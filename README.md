# 🖼️ Convención de íconos para Commits 

| Icono | Tipo de Commit | Nombre / Categoría | Descripción / Uso Recomendado |
| :---: | :--- | :--- | :--- |
| ✨ | feat | *Nueva Funcionalidad* | Añadir una nueva característica o función para el usuario. |
| 🐛 | fix | *Corrección de Error* | Solucionar un fallo o bug en el código. |
| 📝 | docs | *Documentación* | Añadir o actualizar documentación (README, guías, JSdoc). |
| 💄 | style | *Estilos / Formato* | Cambios visuales o de formato CSS/UI sin cambiar lógica de negocio. |
| ♻️ | refactor | *Refactorización* | Mejorar la estructura del código sin cambiar su comportamiento. |
| ⚡️ | perf | *Rendimiento* | Cambios enfocados en mejorar la velocidad o eficiencia. |
| 🧪 | test | *Pruebas* | Añadir, corregir o refactorizar pruebas unitarias o de integración. |
| 🔧 | chore | *Mantenimiento* | Tareas repetitivas, configuración interna o actualización de dependencias. |
| 👷 | ci | *Integración Continua* | Modificar scripts o flujos de CI/CD (GitHub Actions, GitLab CI, etc.). |
| 🚀 | build | *Compilación / Build* | Cambios que afectan el empaquetado o herramientas de build (Vite, Webpack). |
| ⏪️ | revert | *Revertir* | Deshacer o revertir un commit anterior. |
